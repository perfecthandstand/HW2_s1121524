# 記憶翻牌遊戲 (Memory Match Game)

這是「視窗程式設計 (II)」作業二的棋牌類遊戲專案。本遊戲採用 C# Windows Forms 開發，結合圖片翻牌記憶玩法與 TTSMAKER 語音播報功能。

## 👨‍💻 開發者資訊

* **姓名：** 鄭博暐

## 🎮 遊戲特色
* **動態卡牌生成：** 遊戲啟動時會自動打亂 16 張卡牌（8 對圖案）的位置，每次遊玩都有不同的挑戰。
* **防連點機制：** 翻錯牌時有 1 秒鐘的記憶時間，期間內程式會鎖定其他點擊操作，防止遊戲邏輯錯誤。
* **語音音效結合：** 採用作業規定的 TTSMAKER 產生情境語音，包含：
  * 配對成功時播放成功音效。
  * 配對失敗時播放提示音效。
  * 全部破關時播放過關慶祝語音。

## 🛠️ 開發環境
* **IDE:** Visual Studio
* **語言:** C#
* **框架:** Windows Forms App (.NET Framework)

## 🕹️ 遊玩說明
1. 啟動遊戲後，畫面上會出現 4x4 共 16 張蓋著的卡牌。
2. 使用滑鼠點擊任意一張卡牌將其翻開。
3. 接著點擊第二張卡牌：
   * **若兩張卡牌圖案相同**：配對成功，卡牌將保持翻開狀態，並播放成功音效。
   * **若兩張卡牌圖案不同**：配對失敗，卡牌會停頓 1 秒鐘供玩家記憶，隨後自動蓋回，並播放失敗音效。
4. 當所有 8 對卡牌都成功配對後，遊戲過關並跳出恭喜視窗！
